# 个人作品集 · GitHub Pages

## 第一次上线
1. GitHub 新建仓库，例如 `portfolio`
2. 把本目录中的 `index.html`、`assets/`、`.nojekyll`、`README.md` 上传到仓库根目录
3. 打开 `Settings` → `Pages`
4. Source 选择 `Deploy from a branch`
5. Branch 选择 `main`，Folder 选择 `/ (root)`
6. 保存并等待部署

公开链接通常为：
`https://你的用户名.github.io/portfolio/`

如果仓库命名为 `你的用户名.github.io`：
`https://你的用户名.github.io/`

## 后续更新但保持链接不变
只要继续修改并提交同一个仓库中的 `index.html` 或 `assets/` 文件即可。GitHub Pages 链接不会变化。

## 注意
项目中的内部业务字段、商家、人名与数据均已脱敏重构。
